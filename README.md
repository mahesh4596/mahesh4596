## About

I'm a Computer Science student at Chitkara University, mostly living in Java and slowly getting comfortable with the web development side of things. I like problem-solving — both the algorithmic kind on LeetCode/GfG and the "how do I actually structure this project" kind that only shows up once you start building.

Most of what's below came from working on real, complete projects rather than tutorials — a medicine donation platform, a desktop app for a local business, and an e-commerce site for a family store.

### 🩺 MediHope

A full-stack platform connecting **medicine donors** with **people in need**, built to reduce waste from unused medicines. The backend automatically flags and cleans up expired stock on a daily cron job, and file uploads go through OCR/image processing rather than manual entry.

**Frontend:** React 19 · Vite · Tailwind CSS · Framer Motion · React Router · Axios
**Backend:** Node.js · Express · MongoDB (Mongoose) · Cloudinary · Tesseract.js (OCR) · node-cron

### 🏠 PropEase

A Java desktop application for managing real estate operations end-to-end — customers, property listings, property search, and finalized deals — with a dashboard that turns records into reports instead of spreadsheets.

**Stack:** Java 21 · JavaFX · MySQL · JDBC · Maven
**Extras:** iText (PDF reports) · Apache POI (Excel reports) · Jakarta Mail (email notifications)

[![Repo](https://img.shields.io/badge/Repository-View_Code-24292E?style=flat-square&logo=github&logoColor=white)](https://github.com/mahesh4596/propease)

### 🛒 Shiv Shakti General Store

A full grocery e-commerce site built for a real store, covering the whole shopping loop — browsing, cart, checkout, and payment — plus an admin panel to manage products and orders. Also ships as an Android app.

**Frontend:** React · Tailwind CSS · Lucide Icons
**Backend:** Node.js · Express · MongoDB (Mongoose) · Razorpay (payments)

[![Repo](https://img.shields.io/badge/Repository-View_Code-24292E?style=flat-square&logo=github&logoColor=white)](https://github.com/mahesh4596/shiv-shakti-general-store)
